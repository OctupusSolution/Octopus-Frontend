# Merchant (app.octopus.sa)

Business-owner / staff dashboard. React + Vite SPA. Carries all 12 backend modules. Feature-Sliced Design layers + a module/entitlement registry in `app/routes/registry.ts` — see the architecture PDF, Section 5.1, for the full OctopusModule contract and why this hybrid was chosen over plain FSD or micro-frontends.
